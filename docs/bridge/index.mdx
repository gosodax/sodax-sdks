Low-level transfer primitives for when you need asset movement without swap logic: spoke → hub, hub → spoke, and spoke → spoke.

Follow the [bridge usage flow](/developers/packages/foundation/sdk/functional-modules/bridge#usage-flow), then use the [bridge example](/developers/packages/foundation/sdk/functional-modules/bridge#bridge) to submit a transfer.
Check [completion and timeouts](/developers/packages/foundation/sdk/functional-modules/bridge#completion-paths-and-timeout) and [errors](/developers/packages/foundation/sdk/functional-modules/bridge#error-handling) before adding retries.
