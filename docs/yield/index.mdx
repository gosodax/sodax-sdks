Enter and exit leverage-yield vault positions as ordinary intent-based swaps — no vault-specific approvals or bespoke deposit calls.

Both integration paths are live on production: the `@sodax/sdk` leverage yield module, and the HTTP API at `https://api.sodax.com/v1/leverage-yield`. For a step-by-step walkthrough of either, see [Integrate Leverage Yield](/developers/how-to/integrate_leverage_yield).

For an SDK integration, start with the [deposit and withdraw flows](/developers/packages/foundation/sdk/functional-modules/leverage_yield#flows). Review [vault risks](/developers/packages/foundation/sdk/functional-modules/leverage_yield#the-risk-the-spread-can-invert), [completion](/developers/packages/foundation/sdk/functional-modules/leverage_yield#completion-paths-and-timeout), and [errors](/developers/packages/foundation/sdk/functional-modules/leverage_yield#error-handling) before integrating.
