This page takes you from zero to a cross-network swap sourced from Redbelly. No new contracts, no approval for native RBNT, one signed transaction for your user.

<Note>

</Note>

## 1. Install

```bash
npm install @sodax/sdk @sodax/wallet-sdk-core
# or: pnpm add / yarn add
```

## 2. Create a Redbelly wallet provider

Redbelly uses the same `EvmWalletProvider` as every other EVM network, keyed by `ChainKeys.REDBELLY_MAINNET`. The account behind it must have Redbelly network access: without it, the account cannot send the transaction that creates the intent. See [User access](https://vine.redbelly.network/identity/user-access/).

<CodeGroup>
  ```typescript Private key (scripts / bots)
  import { EvmWalletProvider } from '@sodax/wallet-sdk-core';
  import { ChainKeys } from '@sodax/sdk';

  const walletProvider = new EvmWalletProvider({
    privateKey: '0x…', // private key of an account with Redbelly network access
    chainId: ChainKeys.REDBELLY_MAINNET,
    rpcUrl: 'https://governors.mainnet.redbelly.network',
  });
  ```

  ```typescript Browser extension (dApps)
  import { EvmWalletProvider } from '@sodax/wallet-sdk-core';

  // walletClient and publicClient are viem clients for Redbelly mainnet,
  // usually supplied by wagmi from the user's connected EVM wallet
  const walletProvider = new EvmWalletProvider({
    walletClient,
    publicClient,
  });
  ```
</CodeGroup>

Building in React? [`@sodax/wallet-sdk-react`](/developers/packages/connection/wallet-sdk-react) connects EVM wallets for you and hands back a ready-made provider via `useWalletProvider`. See [Wallets](/redbelly/wallets).

## 3. Look up supported tokens

Token addresses and decimals come from the SDK config, so you never hard-code them.

```typescript
import { Sodax, ChainKeys, type XToken } from '@sodax/sdk';

const sodax = new Sodax();

// find() returns XToken | undefined, so narrow before using the address
const bySymbol = (tokens: readonly XToken[], symbol: string) => {
  const token = tokens.find(t => t.symbol === symbol);
  if (!token) throw new Error(`${symbol} is not a supported swap token`);
  return token;
};

const rbnt = bySymbol(sodax.swaps.getSupportedSwapTokensByChainId(ChainKeys.REDBELLY_MAINNET), 'RBNT');
const usdcBase = bySymbol(sodax.swaps.getSupportedSwapTokensByChainId(ChainKeys.BASE_MAINNET), 'USDC');
```

## 4. Quote and swap

`swap()` runs the full lifecycle: it creates the intent on Redbelly, verifies the transaction landed, relays it to the hub, and notifies the solver to fill on the destination network.

```typescript
import type { SolverIntentQuoteRequest } from '@sodax/sdk';

// 100 RBNT, built from the token's own decimals
const inputAmount = 100n * 10n ** BigInt(rbnt.decimals);

// Quote: 100 RBNT -> USDC on Base
const quoteResult = await sodax.swaps.getQuote({
  token_src: rbnt.address,
  token_dst: usdcBase.address,
  token_src_blockchain_id: ChainKeys.REDBELLY_MAINNET,
  token_dst_blockchain_id: ChainKeys.BASE_MAINNET,
  amount: inputAmount,
  quote_type: 'exact_input',
} satisfies SolverIntentQuoteRequest);

if (!quoteResult.ok) throw new Error('Quote failed');
const { quoted_amount } = quoteResult.value;

// `deadline` is an absolute Unix timestamp; getSwapDeadline turns an offset into one
const deadlineResult = await sodax.swaps.getSwapDeadline(300n); // 5 minutes from now
if (!deadlineResult.ok) throw new Error('Deadline lookup failed');

// Execute
const swapResult = await sodax.swaps.swap({
  params: {
    inputToken: rbnt.address,
    outputToken: usdcBase.address,
    inputAmount,
    minOutputAmount: (quoted_amount * 99n) / 100n, // your slippage policy
    deadline: deadlineResult.value,
    allowPartialFill: false,
    srcChainKey: ChainKeys.REDBELLY_MAINNET,
    dstChainKey: ChainKeys.BASE_MAINNET,
    srcAddress: await walletProvider.getWalletAddress(),
    dstAddress: '0x...', // recipient on Base
    solver: '0x0000000000000000000000000000000000000000',
    data: '0x',
  },
  walletProvider,
  timeout: 120_000,
});

if (swapResult.ok) {
  console.log('Submitted. Hub tx:', swapResult.value.intentDeliveryInfo.dstTxHash);
} else {
  console.error('Swap failed:', swapResult.error);
}
```

`ok` means the intent was created, relayed to the hub, and the solver notified, **not** that it was
filled. Poll `sodax.swaps.getStatus({ intent_tx_hash: intentDeliveryInfo.dstTxHash })` until the
status is `SolverIntentStatusCode.SOLVED`, which is the only success signal. The
[main quickstart](/quickstart) has the full polling loop, including why `NOT_FOUND` is not terminal.

A few things to know on Redbelly:

- **RBNT needs no approval.** It is the native token. Swapping an ERC-20 token on Redbelly needs an allowance first; see [Approvals](/redbelly/swaps#approvals).
- **Amounts follow `token.decimals`.** RBNT has 18 decimals, but USDC and USDT on Redbelly have 6. Always build amounts from the token's own `decimals`.
- **No network access, no intent.** If the account has not been enabled on Redbelly, the intent transaction cannot be sent. Have users complete Redbelly's access flow before their first SODAX action.
