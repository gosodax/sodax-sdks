Quote and execute an intent across networks. Solvers on the SODAX marketplace fill it, so you don't manage liquidity or routing.

Start with [Your first swap](/quickstart) for a complete SDK flow from setup to settlement.
For an HTTP integration, follow the [create → submit-tx → poll walkthrough](/developers/http-api/swaps#bot-flow-create-submit-tx-poll).
