Use this recipe when your app runs on Base and you want to be paid in a Base asset, but your users hold something else: USDC on Arbitrum, SOL on Solana, ETH on Ethereum, or any other listed asset. SODAX turns the payment into a single cross-network swap that settles at an address you control on Base. There are no new contracts and nothing for you to run; the payer signs one transaction on the network they are paying from.

## What you will build

A checkout step that takes a payer's token on any supported network, quotes it against USDC on Base, and settles the output at your app's Base address. The example pays 25 USDC from Arbitrum and settles USDC on Base, but the source network and token are interchangeable: read them from the SDK config and pass them straight through.

## Prerequisites

- `@sodax/sdk` installed, plus `@sodax/wallet-sdk-core` (or `@sodax/wallet-sdk-react` in a React app) for the wallet provider.
- A wallet on the network the payer starts from, funded with that network's native token for gas (ETH on Arbitrum in the example).
- Your app's receiving address on Base.
- A SODAX API key kept on your server. See [API keys](/developers/how-to/api-keys).

SODAX is mainnet only, so test with small amounts. See [Is SODAX on Testnet?](/developers/how-to/testnet).

## Steps

<Steps>
  <Step title="Create a wallet provider for the payer's network">
    The payer signs on the network they are paying from, so the provider is keyed to that network, not to Base. Base is only the destination.

    ```typescript
    import { Sodax, ChainKeys } from '@sodax/sdk';
    import type { XToken } from '@sodax/sdk';
    import { EvmWalletProvider } from '@sodax/wallet-sdk-core';

    const sodax = new Sodax();

    const bySymbol = (tokens: readonly XToken[], symbol: string): XToken => {
      const token = tokens.find((t) => t.symbol === symbol);
      if (!token) throw new Error(`${symbol} is not a supported token on this network`);
      return token;
    };

    const walletProvider = new EvmWalletProvider({
      privateKey: payerPrivateKey, // `0x${string}`
      chainId: ChainKeys.ARBITRUM_MAINNET,
      rpcUrl: 'https://arb1.arbitrum.io/rpc',
    });
    ```
  </Step>

  <Step title="Resolve both tokens from config">
    Never hard-code addresses or decimals. Read the payer's token from the source network and your settlement token from Base.

    ```typescript
    const payToken = bySymbol(
      sodax.swaps.getSupportedSwapTokensByChainId(ChainKeys.ARBITRUM_MAINNET),
      'USDC',
    );
    const settleToken = bySymbol(
      sodax.swaps.getSupportedSwapTokensByChainId(ChainKeys.BASE_MAINNET),
      'USDC',
    );

    const inputAmount = 25n * 10n ** BigInt(payToken.decimals); // 25 USDC
    ```
  </Step>

  <Step title="Quote the swap">
    `getQuote` prices the exact input and deducts any configured fee, so `quoted_amount` is the net output that lands on Base.

    ```typescript
    import type { SolverIntentQuoteRequest } from '@sodax/sdk';

    const quoteResult = await sodax.swaps.getQuote({
      token_src: payToken.address,
      token_dst: settleToken.address,
      token_src_blockchain_id: ChainKeys.ARBITRUM_MAINNET,
      token_dst_blockchain_id: ChainKeys.BASE_MAINNET,
      amount: inputAmount,
      quote_type: 'exact_input',
    } satisfies SolverIntentQuoteRequest);
    if (!quoteResult.ok) throw new Error('Quote failed');
    const { quoted_amount } = quoteResult.value;
    ```
  </Step>

  <Step title="Build the intent, approve the input, and execute">
    The destination is Base: set `dstChainKey` to `ChainKeys.BASE_MAINNET` and `dstAddress` to your receiving address. Every ERC-20 input needs an allowance first; native ETH does not. `swap()` runs the whole lifecycle: it creates the intent on the source network, relays it to the hub, and notifies a solver to fill on Base.

    ```typescript
    const swapParams = {
      inputToken: payToken.address,
      outputToken: settleToken.address,
      inputAmount,
      minOutputAmount: (quoted_amount * 99n) / 100n, // your slippage policy
      deadline: 0n, // replaced below with an absolute timestamp
      allowPartialFill: false,
      srcChainKey: ChainKeys.ARBITRUM_MAINNET,
      dstChainKey: ChainKeys.BASE_MAINNET,
      srcAddress: await walletProvider.getWalletAddress(),
      dstAddress: appBaseAddress, // your app's receiving address on Base
      solver: '0x0000000000000000000000000000000000000000',
      data: '0x',
    } as const;

    const allowance = await sodax.swaps.isAllowanceValid({ params: swapParams, walletProvider });
    if (!allowance.ok) throw allowance.error;
    if (!allowance.value) {
      const approval = await sodax.swaps.approve({ params: swapParams, walletProvider });
      if (!approval.ok) throw approval.error;
      // wait for the approval to be mined before calling swap()
    }

    const deadlineResult = await sodax.swaps.getSwapDeadline(300n); // 5 minutes from now
    if (!deadlineResult.ok) throw new Error('Deadline lookup failed');

    const swapResult = await sodax.swaps.swap({
      params: { ...swapParams, deadline: deadlineResult.value },
      walletProvider,
      timeout: 120_000,
    });
    if (!swapResult.ok) throw swapResult.error;
    ```
  </Step>

  <Step title="Confirm settlement on Base">
    A successful `swap()` means the intent was created, relayed, and handed to a solver, not that it filled. Poll `getStatus` until `SolverIntentStatusCode.SOLVED`, which is the only signal the Base asset has landed at `dstAddress`.

    ```typescript
    import { SolverIntentStatusCode } from '@sodax/sdk';

    const hubTxHash = swapResult.value.intentDeliveryInfo.dstTxHash;
    const isHex = (v: string): v is `0x${string}` => v.startsWith('0x');
    if (!isHex(hubTxHash)) throw new Error('Unexpected hub transaction hash');

    for (;;) {
      const status = await sodax.swaps.getStatus({ intent_tx_hash: hubTxHash });
      if (status.ok && status.value.status === SolverIntentStatusCode.SOLVED) break;
      await new Promise((r) => setTimeout(r, 2_000));
    }
    ```
  </Step>
</Steps>

## Error handling

Swap operations return `Result<T>` rather than throwing. Check `ok` on every call and discriminate failures on `error.code`: `getQuote` can fail when no route exists, `swap` returns a typed `SodaxError` union covering creation, relay, and execution, and a quote that looks too small usually means the input does not clear the fees. The base fee is a fixed 0.1% of the input taken by the protocol; any platform fee you add is yours. See [Fees](/base/swaps#fees).
