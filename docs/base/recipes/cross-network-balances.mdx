Use this recipe when your app lives on Base but your users hold assets spread across networks. Before they act, they need to see what they hold everywhere. SODAX reads a user's own wallet with the same call on every network it supports, so a Base app can show a cross-network portfolio and route any holding onto Base.

## What you will build

A portfolio view that reads balances on every network a user has connected, then moves a chosen holding into a Base asset.

## Prerequisites

- `@sodax/sdk`, plus `@sodax/dapp-kit` and a `SodaxProvider` for the React hook.
- The networks and addresses the user has connected.

## How it works

<Steps>
  <Step title="Read one network at a time">
    Each read covers one network, so a broken network never hides the others. A failed network comes back as `null`, never as an empty wallet.
  </Step>

  <Step title="Keep the chain key and token list together">
    Every read uses `token.address` on the network you pass, so a token list from another network reads wrong. Each network's swap-supported list is also the set of holdings a user can route onto Base. Look tokens up by address, not symbol.
  </Step>

  <Step title="Display amounts">
    Balances are `bigint` in the token's smallest unit. Scale them by `token.decimals`. See [Read wallet balances](/developers/how-to/wallet-balances).
  </Step>

  <Step title="Route a holding onto Base">
    Hand the chosen holding to [Accept any token, settle on Base](/base/recipes/accept-any-token): the source is the network and token the user picked, the destination is Base.
  </Step>
</Steps>

## Code

Read every connected network with `@sodax/sdk`:

{/* example: wallet-balances/portfolio.ts#portfolio */}
```ts
import type { Sodax, SpokeChainKey } from '@sodax/sdk';

export async function readPortfolio(sodax: Sodax, wallets: { chainKey: SpokeChainKey; address: string }[]) {
  return Promise.all(
    wallets.map(async ({ chainKey, address }) => {
      const tokens = sodax.swaps.getSupportedSwapTokensByChainId(chainKey);
      const result = await sodax.spoke.getWalletBalances({ srcChainKey: chainKey, srcAddress: address, tokens });
      return { chainKey, balances: result.ok ? result.value : null };
    }),
  );
}
```

Or one network at a time with the `useBalances` hook in `@sodax/dapp-kit`:

{/* example: wallet-balances/Balances.tsx#use-balances */}
```tsx
import { useBalances } from '@sodax/dapp-kit';
import type { SpokeChainKey, XToken } from '@sodax/sdk';

export function Balances({
  chainKey,
  address,
  tokens,
}: {
  chainKey: SpokeChainKey | undefined;
  address: string | undefined;
  tokens: readonly XToken[];
}) {
  const { data: balances, isLoading, error } = useBalances({ params: { chainKey, address, tokens } });

  if (isLoading) return <p>Loading balances…</p>;
  if (error) return <p>Could not read balances.</p>;

  return (
    <ul>
      {tokens.map(token => (
        <li key={token.address}>
          {token.symbol}: {(balances?.[token.address] ?? 0n).toString()}
        </li>
      ))}
    </ul>
  );
}
```
